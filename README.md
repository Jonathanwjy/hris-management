# About

Human Resource Information System (HRIS) is a web-based application developed to streamline employee management processes within an organization. This system helps administrators manage employee data, user accounts, attendance records, leave requests, and other HR-related information in a centralized platform.

The application was developed using Laravel Framework and MySQL Database, focusing on data accuracy, efficiency, and ease of use.
